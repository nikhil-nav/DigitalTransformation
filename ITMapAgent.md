# IT Map Agent

## Business Requirement
IT mapping agent

### The agent will read the provided technical and functional data and map the applications to the created BCM. The provided data will be in excel format, so extracting the agent will perform the extraction via its reasoning and acting capabilities

### The mapped IT to BCM view will be displayed in a separate kanban board showing applications represented alongside different L2 capabilities

###  US 2.1 The mapped IT to BCM view should also get linked to the BCM graph representation. The application will be another node in the graph and link to BCM L1 and L2 Nodes, with a relationship type supported by. For ex "Surgical Equipment"-->(supported by)"SurgiCommandPlatform"
