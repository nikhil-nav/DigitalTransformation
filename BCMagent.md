# BCMCreationAgent

## The chat interface should have agentic framework working behind the scenes. Agents will research the industry domain, company website, annual report, linkedin pages, business news sites,and other relevant information sources, and ask questions from users to create a near to accurate Business Capability map for a enterprise
## BCM Chat Interface should have an option for the user to select the AI model for interaction, research and evaluation with respective api keys
## Business Capability Map should showcase L1, L2 and L3 business functions on the Page
## The interface to showcase a BCM should be user friendly, collapsable and editable, much like a Kanban Board
